# KidsZone library

Game content packs for the KidsZone tablet app. The app reads
`catalog.json` and downloads the files it lists, checking each one's size
and SHA-256 before installing it. Files under `packs/<game>/<version>/`
never change once published; a new version gets a new folder.

Generated by `tool/build_library.py` in the KidsZone repository. Don't
edit by hand.

## Sources

- Maps, states, provinces and cities: [Natural Earth](https://www.naturalearthdata.com)
  (public domain).
- Satellite pictures: NASA's Blue Marble Next Generation, imagery by NASA
  Earth Observatory (public domain).
